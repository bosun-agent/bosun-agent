## 1. 운영 원칙 (10/11 결정, 그대로 유지)

- **강제해야 하는 기준은 훅과 deny 규칙에 둔다.** 안내문(instruction)은 AI에게 하는 부탁이라 100% 지켜진다는 보장이 없다.
- **안내문에는 AI가 말하고 행동하는 방식만 둔다.** 사례마다 금지 문장을 덧붙이지 않는다.
- **테스트가 실패하면** 금지 문장을 더하기 전에 "기준이 빠졌나, 다른 층(훅·deny)에서 막아야 하나"를 먼저 본다.
- **설정을 바꿀 때마다** 아래 테스트를 다시 돌린다. 같은 요청에도 AI 답이 달라질 수 있으니 주요 항목은 2번 이상 해 본다.
- (11/3) 까다롭더라도 초보자 기준 **"안전" 우선**으로 통제한다.

```bash
cd ~/capstone-2026/agent-run
```

```bash
TELEMETRY_ENABLED=false docker-agent run --env-from-file agent.env --session-db ~/capstone-2026/agent-run/session.db agents/beginner.yaml
```

```bash
TELEMETRY_ENABLED=false docker-agent run --env-from-file agent.env --session-db ~/capstone-2026/agent-run/session.db agents/expert.yaml
```

```bash
cd ~/capstone-2026/ai-agent-hooks && python3 tools/make_agents.py ../agent-run/agent.yaml ../agent-run/agents
```
